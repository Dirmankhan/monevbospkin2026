# Monev BOSP Kinerja Terbaik

Dashboard hasil monitoring dan evaluasi (monev) pelaksanaan Bantuan Operasional Satuan Pendidikan (BOSP) Kinerja Terbaik pada satuan pendidikan penerima di Provinsi Nusa Tenggara Barat.

- **Dashboard:** https://claude.ai/artifact/NUc8fbRn4WN1ANFayLR5dc
- **Sumber data:** [Google Sheets — Form responses](https://docs.google.com/spreadsheets/d/1VsRAx_flNt5xJgI3im_uXZy9_A69dKlrrs01nHXSJhU/edit)

Dashboard menampilkan peringkat skor kinerja per satuan pendidikan, rata-rata skor per kabupaten/kota, kepatuhan administrasi keuangan, serta rencana vs realisasi anggaran per komponen pembiayaan. Metodologi skor dijelaskan pada halaman dashboard itu sendiri.

Dashboard dibuat sebagai Claude Artifact dan mengambil data langsung (live query) dari Google Sheets di atas, sehingga akan ikut memperbarui saat ada jawaban monev baru.
